# Human Review Test

Human review should not mean "a person glanced at it".

A reviewer should be able to answer:

- Does every material claim have support in the supplied evidence or a clear inference label?
- Did the model omit contradictory evidence?
- Did it invent owners, dates, decisions, requirements or certainty?
- Does the output preserve important unknowns?
- Is the required structure complete?
- Is the recommendation advisory where human judgement remains authoritative?
- Would I make the same decision if the fluent prose were removed and only the evidence remained?

The CLI can check structure and provenance. It cannot decide whether an enterprise judgement is correct. That boundary is deliberate.
