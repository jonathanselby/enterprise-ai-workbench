# Accepted Useful Work

Model output is not authoritative merely because it is structured, reproducible or well sourced.

A useful operating model is:

```text
INPUT
  |
  v
VERSIONED WORKFLOW
  |
  v
MODEL ANALYSIS / PROPOSAL
  |
  v
DETERMINISTIC CONTRACT CHECK
  |
  v
HUMAN OR NAMED DETERMINISTIC ACCEPTANCE
  |
  v
ACCEPTED USEFUL WORK
```

The model does the work it is good at: extraction, synthesis, comparison, candidate generation and drafting.

Authority stays outside the model. A person or deterministic rule decides whether the result may be relied upon.

The workbench `review` command records that acceptance decision with hashes of the workflow instructions, input and output. The record proves what was reviewed; it does not prove the decision was correct.
