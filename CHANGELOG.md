# Changelog

## 0.1.0

Initial usable release.

- eight reusable enterprise AI workflows;
- versioned machine-readable workflow manifests;
- provider-neutral run-bundle rendering;
- deterministic run IDs and SHA-256 provenance for workflow instructions and input;
- output-contract checking;
- explicit human/deterministic authority boundary;
- review records that hash input, output and skill instructions;
- fictional worked examples for every workflow;
- methods for intent, human review and accepted useful work;
- Go CLI using standard library only;
- unit and acceptance tests in GitHub Actions, including every bundled example.
