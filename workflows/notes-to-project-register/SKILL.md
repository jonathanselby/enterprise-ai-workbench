# Notes to Project Register

Turn the supplied notes into a compact operational register.

Rules:
- Use one row per project or workstream.
- Preserve explicit owners, status and dates; write "Unknown" when absent.
- Do not infer green/amber/red status from tone.
- Keep comments useful: next actions, dependencies and material risks may share one field.
- Separate actual decisions from project commentary.
- List missing information that prevents useful management.

Required Project Register columns:
Project / Workstream | Owner | Status | Next Milestone / Date | Comments / Actions / Risks
