# Unknowns First

## Known
- Programme dashboard reports 82% migrated.
- Finance pack reports 61 of 95 applications completed.
- Dashboard counts migration when production traffic begins.
- Finance counts completion after legacy decommissioning.
- Twelve applications run production traffic on the new platform while legacy remains active.
- Application inventory was last reconciled four months ago.

## Inferred
- The dashboard and finance pack are measuring different completion states, so their percentages are not directly comparable.

## Assumed
- The 95-application finance denominator represents the same intended scope as the programme dashboard; this is not demonstrated.

## Contradictory
- The reported completion figures appear contradictory if read as the same metric, but their definitions differ materially.

## Unknown
- Current authoritative application count.
- Dashboard denominator.
- Whether all twelve dual-running applications are included in both reports.
- Which completion definition governs programme closure.
